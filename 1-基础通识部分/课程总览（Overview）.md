# 课程总览（Overview）

## 1. 这是什么

一份面向高中生的「大语言模型 + 人机协作」课程的**20 分钟讲授版**，共 8 节课（L1–L8）。每课保留「内容引入 + 知识点讲授（含时间安排表）」，不包含课后练习；另附「教师答疑参考」供备课。

***

## 2. 课程主线：考一本入门级的「AI 驾照」（给中学生降维理解的类比）

整门课 = 考一本入门级的 AI 驾照：**理解发动机原理（训练层）→ 选车（过渡）→ 会开车（推理层）→ 守交规（伦理织入每一层）**。

主类比唯一口径是「车」：

| **概念**                  | **汽车类比**                                                          |
| ----------------------- | ----------------------------------------------------------------- |
| 基座模型                    | 发动机（核心、极重资产）                                                      |
| 后训练 / 对齐（SFT/RLHF）      | 发动机调校 + 电控（更「听话好用」）                                               |
| Transformer             | 发动机的设计图 / 机械原理                                                    |
| Token                   | 燃油（最小计量与计费单位）                                                     |
| 推理架构（CoT/ToT/ReAct/PaE） | 驾驶策略 / 半自动辅助                                                      |
| RAG                     | 车载导航 / 外挂地图                                                       |
| **Harness / 驾驭层**       | **整车里「发动机以外的一切」**；人机交互部分 = 驾驶舱（档位=编排 / 仪表=上下文·记忆 / 按钮=工具 / 气囊=护栏） |
| 聊天机器人 / 助手 / 智能体        | 轿车 / 辅助驾驶 / 自动驾驶                                                  |

> 局部类比：训练 vs 推理的「权重冻结」→ 厨艺/手艺定型（练手艺=训练，点单做菜=推理）。仅用于解释「推理时不学习」这一点。

***

## 3. 技术向的锚点

贯穿 L1–L8：

* **模型 = 一个无状态函数**：`输出 = 模型(系统提示词 + 工具 + 会话历史 + 其他上下文 + 用户指令)`
* **两条硬约束**：①无状态（不自动记住上次）；②知识截止训练日期。
* **Agent = Model + Harness**（智能体 = 模型 + 驾驭层）。
* **四层工程链**：Prompt → Context → Harness → Loop。
* **Harness 三类**：驾驭（Steer）/ 约束（Constrain）/ 整合（Integrate）。
* **工具调用**：模型只生成调用请求；持有密钥、发起请求、改数据的是模型外的 Agent/程序；权限/审批/审计在外部。
* **System Prompt**：给 AI 定角色，但**只能引导，不能强制**。
* **两个核心结论**：①模型决定能力上限；上下文 + Harness 决定能否稳定落地。②人负责选方向/定标准/担责任；Agent 负责执行/验证/加速。

## 4. 八课路线（L1–L8）

| **课**             | **层**   | **核心问题**                | **汽车类比**                                 |
| ----------------- | ------- | ----------------------- | ---------------------------------------- |
| **L1** 整体定位       | 鸟瞰      | 我用的是哪种 AI？它和别的 AI 什么关系？ | 产品=车，本体=发动机；自主程度谱系                       |
| **L2** 剖析内部机制     | 打开盖子    | 它内部怎么运转？                | 打开发动机（token+transformer）/打开车（Harness 循环） |
| L3 Token 是什么      | 训练·输入   | 模型怎样「读」文字？              | Token = 燃油 + Embedding                   |
| L4 为什么 AI 有时强大有时蠢 | 训练·结构   | 为什么会漏条件、算错、忘前文？         | Transformer=发动机设计图；注意力=找重点               |
| L5 不同 AI 为什么表现不同  | 训练→推理过渡 | 不同模型/产品为何差异大？如何选型？      | 懂发动机变种→选车型                               |
| L6 怎样让 AI 听你的     | 推理·驾驶基础 | 怎样把意图说清楚？               | 提示词 = 方向盘                                |
| L7 AI 怎样完成复杂任务    | 推理·扩展   | 如何让车调用外部能力？             | 工具调用 = 装外设                               |
| L8 复习助手智能体设计      | 推理·自治   | 何时该让「车」自己开？             | 智能体 = 自动驾驶                               |

贯穿示例：**「考前知识点复习助手」**——一个 AI 学习支持智能体。

```text
下周三有一场考试，我有两个知识点总是搞混。每天晚上大概有 45 分钟复习时间。
请帮我整理重点、安排 5 天复习计划，并给我几道自测题。
```

***

## 5. 每课结构（20 分钟讲授版）

1. **内容引入**（约 3 分钟）：用一个场景、对比或样例提出本课问题。
2. **知识点讲授**（约 20 分钟）：核心概念，含「知识点讲授时间安排」表。每课顶部有一&#x884C;**「本课位置 + 汽车类比定位」**，把本课挂回 AI 驾照主线。
3. **教师答疑参考**（附录，不计入 20 分钟）：预判学生提问并给推荐回答。
