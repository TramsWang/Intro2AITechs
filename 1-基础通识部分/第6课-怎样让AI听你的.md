# 第6课：怎样让 AI 听你的

> **本课在课程里的位置**：推理层·驾驶基础。进入学生天天在用的能力——把意图说清楚。
> **汽车类比定位**：提示词 = 方向盘 / 给导航（参 OpenAI、Anthropic 官方提示词指南）。

## 内容引入

**3 分钟互动：一句话需求为什么不够？**

教师展示两个提示词：

```text
帮我复习。
```

```text
你是一名高中老师。学生下周三有考试，有两个总是搞混的知识点，每天晚上可复习 45 分钟。
请先列出这两个知识点最容易混淆的地方，再用表格安排 5 天复习计划，最后给 6 道自测题。
无法确认考试范围时，请标注"需要向老师确认"，不要承诺一定提高成绩。
```

请学生比较：第二个提示词多了哪些信息？哪些信息会让回答更具体、更可检查？

## 知识点讲授

### 1. 提示词为什么有效

大模型根据上下文生成后续内容。提示词就是给模型提供任务目标、背景、限制、格式和检查标准，让模型更容易生成符合要求的输出。

提示词不是魔法。它不能让模型知道没有提供的最新事实，也不能保证复杂计算一定正确，但它能显著减少模糊性、漏条件和格式混乱。

**两种提示词，分清楚**：你在输入框里打的是**用户提示词（User Prompt）**；而产品在你背后，还会悄悄给模型一段**系统提示词（System Prompt）**——它给 AI 定角色、能力边界、安全规则和交互风格（比如"你是一名高中老师"）。但要注意：**系统提示词只能"引导"模型，不能"强制"模型**——真正的权限、审批、护栏要靠模型外面的工程（Harness）来保证，不是写在提示词里就万事大吉。

### 2. 复习提示词四要素

| 要素 | 检查问题 | 复习助手例子 |
| ---- | -------- | ------------ |
| 任务 | 要 AI 做什么？ | 整理重点、安排计划、生成自测题 |
| 要求 | 必须遵守哪些限制？ | 每天不超过 45 分钟，不确定范围要标注 |
| 格式 | 输出长什么样？ | 表格、清单、题目和答案解析 |
| 场景 | 用户是谁、背景是什么？ | 下周三有考试，两个知识点搞混 |

### 3. 提示词四原则

| 原则 | 常见问题 | 改进方式 |
| ---- | -------- | -------- |
| 全面性 | 漏了考试时间、薄弱点、可用时间 | 补齐影响结果的条件 |
| 一致性 | 要 5 天计划却要求 3 行表格 | 检查要求之间是否冲突 |
| 简洁性 | 抱怨很多但条件不清楚 | 删除无关信息，保留关键约束 |
| 合理性 | 要求一天 45 分钟完成 100 道大题 | 调整到真实可执行 |

### 4. 五种常用提示词技巧

**角色设定：** 让模型明确回答视角和边界。

```text
你是一名高中老师，请用适合高中生理解的语言解释。
```

**样例提示：** 给模型一个输入和输出样例，让它模仿结构。

```text
请参考样例生成知识卡片：
知识点：氧化还原反应
一句话解释：有电子转移（化合价升降）的反应。
易错点：不要只看有没有氧气参与。
自测题：判断 Fe + CuSO₄ → FeSO₄ + Cu 是否为氧化还原反应，并说明理由。
```

**分步提示：** 要求模型按顺序完成任务。

```text
第一步整理混淆点，第二步安排 5 天计划，第三步生成自测题，第四步列出需要老师确认的内容。
```

**结构化输出：** 规定字段和格式，方便检查。

```text
请用表格输出：日期、复习目标、关键知识点、练习任务、检查标准、需要确认的内容。
```

**选择对话上下文：** 告诉模型应该使用或忽略哪些信息。

```text
请只依据下面这段学生信息制定计划，不要使用前面对其他科目的讨论内容。
```

### 5. 提示词迭代

提示词通常不是一次写完就最好。实际使用中可以按下面循环迭代：

```text
观察输出
  ↓
找出问题
  ↓
补充约束或样例
  ↓
要求自检
  ↓
重新测试
```

例如输出太泛，可以补充考试时间、薄弱点和输出格式；漏掉 45 分钟限制，可以把限制前置，并要求模型先复述约束；编造考试范围，可以要求"无资料时标注需要老师确认"。

### 6. 不同任务的提示策略

| 任务 | 提示重点 |
| ---- | -------- |
| 解释概念 | 说明对象年级、先直觉再例题、列易错点 |
| 总结文章 | 指定范围、输出层级、保留依据 |
| 写作修改 | 说明目标风格、保留原意、列修改理由 |
| 生成计划 | 写清时间、目标、限制、检查标准 |
| 出题自测 | 指定知识点、难度、题型、答案解析 |
| 分析错误 | 要求定位错因、对应知识点、补救练习 |
| 比较方案 | 说明评价标准和优先级 |

### 7. 提示词不能解决所有问题

提示词能改善输出，但不能替代所有工具和判断：

- 最新事实要搜索并核查来源；
- 复杂计算要用代码或计算器；
- 长文档要分段、摘要或使用 RAG 匹配指定资料片段；
- 隐私敏感内容要少输入或使用安全环境；
- 高风险判断要交给老师、家长或专业人员；
- AI 输出仍要检查依据和风险。

## 教师答疑参考（附录，不计入 20 分钟）

1. 学生可能会问：有没有一条万能提示词，可以让 AI 什么都答好？

   推荐回答：没有。提示词要服务具体任务。解释概念、生成计划、修改作文、分析错题、比较方案需要的背景、格式和检查标准都不同。通用模板可以作为起点，但必须根据任务调整。

2. 学生可能会问：角色设定写得越厉害，AI 回答就越专业吗？

   推荐回答：角色设定能帮助模型选择语气、角度和表达层次，但不能凭空补足事实、工具和专业验证。写"你是顶级专家"不如写清楚对象、任务、资料来源、输出格式和检查标准。

3. 学生可能会问：为什么我已经写了清楚提示词，AI 还是会错？

   推荐回答：提示词只能减少模糊性，不能解决所有问题。如果需要最新信息、指定资料、复杂计算、图片识别或正式判断，就还需要搜索、RAG、代码、多模态工具或人工确认。

4. 学生可能会问：样例提示会不会让 AI 只会照抄样例？

   推荐回答：样例的作用是让模型理解结构和质量标准。为了减少照抄，可以明确写"参考格式，不要复用样例内容"，并提供新的输入、输出字段和评价标准。

5. 学生可能会问：让 AI 先自检，结果是不是就一定可靠？

   推荐回答：自检能帮助发现漏条件、格式问题和明显矛盾，但不能保证事实正确。对于来源、计算、考试范围、隐私和安全问题，仍然需要工具核查或人工确认。
