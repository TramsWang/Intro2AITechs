**3 分钟互动：听到「AI」，你脑子里冒出什么？**

教师收集学生联想（ChatGPT、扫地机器人、钢铁侠、自动驾驶、科幻里的 AGI……），原样摊在黑板/屏幕上。

教师点破：你看，「AI」在大家脑子里是一个**宏大又模糊的团块**——聊天框、机器人、科幻大脑全搅在一起。今天这节课只做一件事：**画一张定位地图，把这些东西放到对的位置**。我们要回答两个问题——

> 我用的是哪种 AI？它和别的 AI 到底什么关系？

## 知识点讲授

### 1. 先把「AI」这个大筐收拢：我们聚焦 LLM

「AI」是一个很大的筐。从外到内一层层收拢：

```text
人工智能 AI
├─ 符号智能等其他路线
└─ 机器学习
   └─ 深度学习
      ├─ 大语言模型（LLM）
      ├─ 多模态模型（可融合语言、图像、声音等）
      └─ 其他网络模型

应用层：围绕模型构建产品和智能体，用提示词工程引导任务。
```

结合 PPT 第 3 页技术全景图，区分技术体系与应用层：大语言模型、多模态模型描述模型能力；提示词工程描述使用方法；智能体描述系统形态。这些不是同一维度的分类。多模态模型与语言模型可以结合，不宜简单说所有多模态模型都是 LLM 的超集。

本课程聚焦语言大模型及其应用。ChatGPT、豆包等是产品名称，产品中使用的模型与产品本身需要分开理解。

> 提示：这里只做收拢，不顺便讲机器学习/深度学习本身——抵制「展开讲讲」的冲动。

### 2. 三个常被乱混的词，先「停」到正确车位

有三个词大家都听过，但常被混为一谈。先给它们找到正确位置（只定位，不展开）：

- **AGI（通用人工智能）**：整个 AI 圆圈的「愿景外边界」，**尚未实现**。它是一个目标，不是某一层现成技术。→ 相关，但不是今天的事。
- **具身智能**：有**物理身体**、能感知+行动的 AI（人形机器人、无人机、机械臂）。常建在「多模态模型 + 智能体 + 身体」之上。→ 相关，但**非本课焦点**（本课聚焦软件/语言侧）。
- **智能体（Agent）**：一种**产品/系统形态**（围绕模型搭起来的系统），**不是一种模型类型**。→ 本课后面专门讲。

### 3. 产品形态：一条「自主程度」的光谱

你日常用的 AI，其实排在一条**自主程度的光谱**上（不是三个干净的盒子）：

| 级 | 形态 | 行为 | 例子 | 车类比 |
|---|---|---|---|---|
| 1 | 聊天机器人 Chatbot | 只对话应答，不主动行动 | ChatGPT 聊天、豆包、元宝 | 轿车（手动） |
| 2 | 助手 / Copilot / Work | 建议/执行**受限**任务，需你监督 | ChatGPT Work、GitHub Copilot | 辅助驾驶 |
| 3 | 智能体 Agent | 给目标，自主规划+多步+工具+反思 | Claude Code、OpenAI Codex、腾讯 Workbuddy、Manus | 自动驾驶 |
| (4) | 多智能体 / 全自主 | 多 agent 协作，更高自主 | （前沿） | 车队 / 全自驾 |

**关键点破**：很多人以为「Work 模式」和「智能体」是两回事，但 **Codex、Workbuddy 其实都是 agent**——「Work 模式」常常就是较轻的 agent。所以与其分三个盒子，不如理解为一条**自主程度的光谱**。你日常最多用的是 chatbot（级 1），但形态正在快速「右移」。

### 4. 产品 vs 本体：你最常踩的认知坑（本课重点）

上面这些 chatbot / Work / agent，全是**产品（车）**；里面使用的**大模型本体（发动机）**可以相同，也可以不同。怎么坐实这个区别？看模型的**两条硬约束**：

- **模型本体是无状态的**：它本身**不会自动记住上一次对话**。你能连续聊，是因为**产品**在外面帮你存了历史和记忆。
- **模型本体的知识有截止日期**：训练完成之后发生的事，它默认**不知道**。你能问到最新消息，是因为**产品**给它接了搜索、文件、工具。

所以一个准确的认识是：

> **模型本体 = 无状态 + 有截止日的「发动机」；你每天摸到的，是外面加了状态、记忆、工具、上下文的「产品（车）」。** 同一台发动机，套上不同的车（不同的驾驭层 Harness），开起来完全不同。

很多人把「产品」当成了「大模型」——这是本课要纠正的核心误解。

#### 对照 PPT 的整车结构与豆包示例

| 产品部件 | 汽车类比 | 作用 |
| ---- | ---- | ---- |
| Model：模型 | 发动机 | 根据输入决策、生成 |
| Tool：工具 | 车轮 | 获取信息、执行操作 |
| Harness：驾驭层 | 车架与底盘 | 编排调用、管理上下文与权限 |
| UI：操作界面 | 方向盘 | 接收用户请求、展示结果 |
| Product：产品 | 整车 | 把各部分组合成可使用的应用 |

按 PPT 第 7 页追踪一次请求：用户向**豆包产品**输入语音或图片，产品调用语音转换等能力，组织文本与图片输入 **Seed 系列模型**；模型可以生成工具指令，产品执行网络搜索或知识库查询，再把工具结果送回模型，最后向用户呈现文字、图片或引用。这是教学化流程示意，具体链路随产品实现而异。

课堂提问：搜索结果是谁取得的？对话历史存在哪里？让学生在图上分别指出工具、驾驭层与模型。

### 5. 能力祛魅（安全版）：它不是全知的科幻大脑

不打开引擎盖（机制留给第 2 课），但先建立警觉：

- 它**不是全知**——知识有截止日，会过时；
- 它会**一本正经地胡说（幻觉）**——表达流畅 ≠ 内容正确；
- 它有**能力边界**——会犯错、会被误导、算不准某些东西。

所以要用**批判眼光**、要**核实来源**、要知道「**它能说 ≠ 它对**」。

> ⚠️ 守卫条款预告：本课**不**用「= 预测下一个词」来祛魅——那个命题及其争议，留到第 2 课诚实讨论。今天只做能力/边界层面的祛魅。

### 6. 这门课 = 考一张「AI 驾照」

把今天收束成一句话：这门课 = 考一张 **AI 驾照**。

- 今天（第 1 课）：**认清路况和车型**——定位。
- 下一节（第 2 课）：**打开引擎盖**——剖开它的内部机制。
- 再往后：**懂发动机（训练层）→ 选对车（选型）→ 会开车（推理层：提示词、工具、智能体）→ 守交规（伦理织入每一层）**。

**「所以呢」**：定位清了，你已经是半个明白人——知道自己在开什么车，也知道它不是神。

## 教师答疑参考（附录，不计入 20 分钟）

1. 学生可能会问：ChatGPT 和 GPT-4 是一回事吗？

   推荐回答：不是。GPT-4 是**模型本体（发动机）**；ChatGPT 是**产品（车）**——它在 GPT-4 这台发动机外面，加了对话界面、历史记录、联网搜索、文件上传等。同一个模型可以被打包成不同产品。

2. 学生可能会问：那 AGI 是不是马上就要实现了？

   推荐回答：AGI 是一个**愿景目标**，目前**尚未实现**。现在的 LLM 和智能体能力在快速提升，但「是否构成 AGI」本身也没有统一定论。把它当作「相关但还没到」的远方，不要被科幻叙事唬住。

3. 学生可能会问：智能体是不是比聊天机器人更「高级」的模型？

   推荐回答：不是「更高级的模型」，而是**不同的产品形态**。智能体和聊天机器人可以用**同一台模型**，区别在于外面的「驾驭层（Harness）」更复杂——能自己规划、调工具、反思。这是**自主程度**的差异，不是模型本身的差异。

4. 学生可能会问：既然模型无状态，为什么我每次聊天它都记得我说过什么？

   推荐回答：因为**产品**帮你把历史对话存了下来，每次提问时把历史一起喂给模型。模型本体本身不记事，是产品在外面给它「续上了记忆」。这也是「产品 ≠ 模型本体」的一个直接证据。

5. 学生可能会问：那它到底有没有「理解」我说的话？

   推荐回答：这是一个**连顶尖专家都还在争论**的问题，我们会在第 2 课专门、诚实地讨论它——今天先不下结论。今天只需要知道：它的表达很流畅，但「流畅 ≠ 正确」，所以永远要核实。
