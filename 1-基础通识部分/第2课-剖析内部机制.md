# 第2课：剖析内部机制——它内部怎么运转？

> **本课在课程里的位置**：从鸟瞰「打开盖子」下探一层——**概念性解剖**（不钻到第 3/4 课的细节）。顺带回答「为什么是 LLM 改变了世界」「为什么要学 token、transformer 那么深」。
> **汽车类比定位**：LLM = 发动机（进燃油 token → 按设计运转 transformer → 输出动力）；智能体 = 模型 + 驾驶舱/控制系统（Harness）。

## ⚠️ 本课特别守则（守卫条款）

> **「大模型 = 预测下一个词」在本课出现，但只作为「机制事实 + 一个未决争议」，绝不是课程基准点。** 讲法见讲授第 2 节。这一节是本课的红线。

## 内容引入

**3 分钟互动：打开引擎盖——它在脑子里到底在干什么？**

上一节课我们把「产品 vs 模型本体」分清了：你摸到的是车，里面那台是发动机。今天**打开引擎盖**，往里看一层——这台「会说话的发动机」本体，到底在干什么？

教师抛出问题：它不是从固定答案库里复制回答，那它**一句话接一句话**到底是怎么来的？

## 知识点讲授

### 1. LLM 机制（概念层）：一个词一个词地往后猜

不钻细节，先建立最简心智模型：

```text
输入 = token（文字被切成小单位）
  ↓
预测器 = Transformer（发动机的设计/原理）
  ↓
输出 = 预测「下一个 token」
  ↓
把下一个 token 接回输入，循环 → 生成一整段话
```

一句话：**它在「一个词一个词地往后猜」**。每猜出一个词，就把这个词接回去当新的上文，再猜下一个——一段完整的回答，是这样**循环**出来的。

> 汽车类比：发动机 = 进燃油（token）→ 按设计运转（transformer）→ 输出动力（下一个 token）。
> 📌 细节（token 怎么切、transformer 怎么并行、为什么能记住上下文）**留给第 3、4 课**，今天只要这个抽象。

### 2. 🔴「预测即理解？」——一个连专家都还在吵的问题（守卫条款核心）

刚才那句「它在猜下一个词」是**事实**：GPT 类大模型的**训练目标/核心机制**确实是预测下一个 token。这是祛魅的起点——**它不是魔法，不是大脑，是一台在猜下一个词的机器**。

但是——**「猜到极致，到底*意味着什么*？」这是一个当今科学界激烈争论、未有定论的问题。** 把两派摆出来：

- **「随机鹦鹉」派**（Bender、Gebru 等，2021）：它只是在统计上模仿人类的语言，**并没有真正理解**，像一只背了很多话的鹦鹉。
- **Ilya Sutskever 派**：要预测得足够好，模型**必须**学到语言背后的「现实世界模型」——「预测得好 = 理解了底层现实，不是统计」。

**再加一条**：现代大模型早已不只是「纯预测」——还叠加了 **RLHF（人类反馈对齐）**、**推理搜索**（如推理模型一步步想）等，比「猜下一个词」复杂得多。

**给学生的态度（落点）**：这个问题**连顶尖专家都还在吵**。我们这节课**不下结论**，而是学会**带着这个开放问题往下学**——既不神化它（「它觉醒了」），也不矮化它（「它只会背书」）。面对一个未决的科学问题，诚实地悬置判断，本身就是一种能力。

> 这是「如何对待一个未决问题」的科学观教学，不是知识灌输。

### 3. 模型 = 一个「无状态函数」+ 两条硬约束

把发动机再抽象一刀：**模型本体就是一个函数**——你给输入，它给输出。

```text
输出 = 模型( 系统提示词 + 工具 + 会话历史 + 其他上下文 + 用户指令 )
```

它有**两条硬约束**，决定了为什么模型外面必须再套一层东西：

1. **无状态**：它**不自动记住上次**。每次调用都是「重新看一遍你给它的全部上下文」。
2. **知识截止训练日期**：训练之后的事，它**默认不知道**。

这两条约束直接回答了一个问题：**既然模型这么强，为什么还需要「智能体/产品」？** 因为模型本体——

- **不记事**（无状态）→ 需要产品在外面存历史和记忆；
- **不知新事**（知识截止）→ 需要在外面接搜索、联网；
- **不会动手**（它只能生成文字，**持有密钥、发起请求、改动数据的不是模型**）→ 需要在外面接工具，并由外部程序执行。

这些「外面的东西」（状态、记忆、工具、编排、护栏）合起来，就是**Harness（驾驭层）**。

### 4. 顺带回答：为什么是 LLM 改变了世界

把第 1 节的机制当脊柱，这个问题自然有答案：

- **以前的深度学习 = 专用工具**：一个网络只干一件事——认图、翻译、下棋，各是各的窄工具。
- **LLM = 通用基座**：一台「猜词」发动机，靠**自然语言**就能驱动千千万万件事。

从「很多窄工具」到「一台通用发动机」——这就是 LLM 让人觉得「智能来了」的根本原因（也是「From Tools to Agents」的转折点）。

*从属佐证（不铺成清单）*：Transformer 能**并行**训练（→ 训练得动大模型）、**规模法则**（越大越强）、**GPU** 算力普及、海量**数据**、**RLHF** 让它「会聊天」——这些汇聚，造就了 2022/23 的爆发。

### 5. 智能体 = 模型 + Harness 循环

接住第 1 课推出的「智能体」，剖开它内部：

```text
给一个目标
  ↓
规划（拆步骤）→ 执行（调工具/生成）→ 观察（看结果）→ 反思（调整）
  ↓ 循环，直到完成
```

所以一句准确的定义：**智能体 = 模型 + Harness（驾驭层）**。

- 第 1 课的 chatbot / copilot / agent，本质是**自主程度不同的 Harness**（轿车 / 辅助驾驶 / 自动驾驶）。
- **Harness = 整辆车里「发动机以外的一切」**；它的**人机交互部分 = 驾驶舱 cockpit**：档位=编排控制、仪表=上下文/记忆、按钮=工具（Functions）、气囊=护栏。

> 📌 Harness 工程的实操（编排循环、工具实现）留给第 7、8 课，今天只点明结构。

### 6. 8 课路线图 + 两个核心结论 + 驾照收束

有了第 1、2 课这张「定位 + 解剖」图，接下来的路线是沿深度逐层下钻：

```text
训练层（懂发动机）：第3课 token/向量化 → 第4课 Transformer 为什么能并行、训练能耗
过渡 + 选型：       第5课 训练→推理，以及「按任务选对车」
推理层（会开车）：   第6课 提示词（方向盘）→ 第7课 工具调用（装外设）→ 第8课 智能体（自动驾驶）
伦理 = 交规，织进每一层。
```

用**两个核心结论**收束今天：

> ① **模型决定能力上限**（靠训练/后训练/强化学习）；**上下文和 Harness 决定这个上限能不能稳定落地**（靠工程）。
> ② **人负责选方向、定标准、担责任；智能体负责执行、验证、加速迭代。**

**「所以呢」**：定位清了、盖子也打开了——你不再是被 AI 神话唬住的人，而是一个**正在拿驾照的驾驶者**。

## 教师答疑参考（附录，不计入 20 分钟）

1. 学生可能会问：它一直在「猜下一个词」，那是不是说明它其实啥都不懂？

   推荐回答：这是一派观点（「随机鹦鹉」派），但**不是定论**。另一派（Ilya 等）认为预测得够好就等于学到了世界模型。而且现代模型还叠加了 RLHF、推理搜索，远比「纯猜词」复杂。这个问题**专家还在吵**，我们不下结论——重点是学会带着开放问题继续学。

2. 学生可能会问：Transformer 到底是什么？今天为什么不讲？

   推荐回答：Transformer 是这台发动机的**设计图/原理**（解释它为什么能转、为什么能并行）。今天是「概念性解剖」，只要知道「输入 token → transformer → 输出下一个 token」就够；它**怎么并行、为什么需要 GPU、和前代技术有什么区别**，是第 4 课的主菜。

3. 学生可能会问：既然模型无状态、又不会动手，那它是怎么帮我查资料、订日程的？

   推荐回答：那些都不是模型本体干的，而是**外面的 Harness（驾驭层）**干的——模型只负责「生成调用请求」（比如『帮我搜索 X』），**真正发起请求、改数据、记日程的是外部程序**，结果再喂回模型。这正是第 7、8 课要讲的工具调用和智能体循环。

4. 学生可能会问：RLHF 是什么？为什么它让 ChatGPT 不一样？

   推荐回答：RLHF 是「人类反馈对齐」——用人的反馈去调整模型，让它更「听话、好用、安全」。这是 ChatGPT 区别于更早的 GPT-3 的关键一步，也是它能在 2022/23 引爆大众的重要原因。细节属于训练侧，第 5 课会再碰到。

5. 学生可能会问：那智能体最终会不会完全替代人？

   推荐回答：用一个核心结论回答——**人负责选方向、定标准、担责任；智能体负责执行、验证、加速**。能力越强，越需要清楚「**能做 ≠ 该自动做**」（第 8 课会专门讲）。高风险、要担责的判断，始终需要人在。
