# 第1课：你每天在用的 AI 到底是什么

## 前一节课内容回顾

**3 分钟回顾：从日常经验进入新模块**

本课是 8 课时版本的第一节课，没有上一节课内容。教师可以把“前课回顾”处理为学生已有经验回顾：请学生回想今天或最近一周使用过的 AI 功能，例如聊天助手、搜索问答、拍照识图、语音输入、短视频推荐、翻译、写作辅助、代码助手、学习规划工具等。

教师把学生回答暂时写成三列：

| 工具或场景 | 它接收什么 | 它输出什么 |
| ---------- | ---------- | ---------- |
| 聊天助手 | 文字问题 | 文字回答 |
| 拍照识题 | 图片 | 题目解析 |
| 搜索问答 | 问题 | 带来源的信息 |

这一步不急着判断对错，只让学生先意识到：他们每天接触的“AI”并不是同一种东西。有的是模型能力，有的是产品功能，有的是外部工具组合。本节课要先建立一张全局地图。

## 内容引入

**3 分钟互动：同一个复习请求，可以交给哪种 AI？**

教师展示贯穿案例请求：

```text
下周三要考物理，我对电路分析和电磁感应总是混淆。每天晚上大概有 45 分钟复习时间。请帮我整理重点、安排 5 天复习计划，并给我几道自测题。
```

请学生判断：这个请求只需要普通聊天机器人吗？如果要更可靠，它可能还需要哪些能力？

学生可能会提出：

- 要能读老师的复习资料；
- 要能根据错题记录判断薄弱点；
- 要能生成计划和自测题；
- 如果考试安排有变化，要能查最新通知；
- 如果涉及个人成绩或错题本，要注意隐私。

教师引出本节核心：一个 AI 产品到底能做什么，不只取决于“大模型聪不聪明”，还取决于它接了哪些工具、能处理哪些输入、有没有知识库和权限边界。

## 知识点讲授

### 1. 从生活中的 AI 产品说起

学生接触的 AI 产品可以先按任务形态观察：

- 聊天生成：回答问题、写作、总结、翻译；
- 搜索增强问答：先查网页或资料，再整理答案；
- 文件/知识库问答：读取讲义、文档、错题本，再基于材料回答；
- 多模态工具：看图片、听语音、识别手写题、处理表格或视频；
- 代码/数据处理助手：写代码、运行代码、统计数据、整理文件；
- Agent/自动化工具：围绕目标拆任务、调用工具、根据反馈继续推进；
- 垂直场景助手：学习助手、客服助手、编程助手、办公助手等。

这些工具都可能被叫作“AI”，但背后的能力组合并不相同。

### 2. 大模型技术全景图

本课用简化地图理解几个概念：

```text
人工智能
  └─ 机器学习
      └─ 深度学习
          ├─ 大语言模型
          ├─ 多模态模型
          └─ 其他神经网络模型

大模型产品
  ├─ 模型本身：提供理解、生成、推理和多模态能力
  │   ├─ 模型接口/API：把模型能力接入聊天、学习、搜索和办公产品（第1课）
  │   ├─ 生成机制：根据上下文连续预测下一个 token（第2课）
  │   └─ token、embedding 和上下文窗口：决定资料怎样进入模型、能装下多少信息（第3课）
  ├─ 模型训练和相关定制服务：让模型或知识能力更贴合具体任务
  │   ├─ 注意力、算力和模型大小：影响速度、成本、遗漏和推理表现（第4课）
  │   ├─ 模型部署：云端、本地化、权限、成本、速度和隐私边界（第4课）
  │   ├─ 预训练、指令训练、聊天对齐：让模型从会续写到会按要求回答（第5课）
  │   ├─ 微调/定制训练：用专门样本强化特定风格、流程或领域能力（第5课）
  │   ├─ 模型选型：快模型、强推理模型、长上下文模型、多模态模型、开源/闭源模型（第5课）
  │   └─ 评估与安全对齐：比较效果、发现幻觉、设置输出边界（第5课）
  └─ 大模型智能体：把模型、提示词、知识和工具组织成能推进任务的系统
      ├─ 提示词和对话界面：把模糊需求改成清晰任务、要求、格式和场景（第6课）
      ├─ 规划与执行：PaE、ReAct、思考模式、反馈和调整（第7课）
      ├─ 工具调用：搜索、RAG、代码和多模态工具（第7课）
      ├─ 记忆、日志、权限和人工确认：控制智能体能记什么、能做什么、何时停下来（第8课）
      └─ 场景化智能体方案：例如复习助手，整合模型选型、RAG、工具、评估和安全边界（第8课）
```

人工智能是最大的概念，指让机器完成识别、判断、推荐、生成、对话和辅助决策等任务。机器学习是实现人工智能的重要方法，强调从数据中学习规律。深度学习是机器学习的一种，常用神经网络处理复杂信息。大语言模型是深度学习在语言和知识任务上的典型成果。

这张图也是后续 8 课的路线图：先分清自己用的是模型、产品、工具还是智能体，再理解生成、token、embedding、上下文、注意力、训练、模型选型、提示词、RAG、工具调用和智能体设计。

智能体不是“有了意识的大模型”。它更像一个系统：把模型、提示词、流程、工具、知识库、记忆、权限和评估组织起来，围绕目标持续完成任务。

### 3. AI 产品形态谱系

同一个复习请求，放到不同产品中会得到不同处理方式：

| 产品形态 | 可能做法 | 优势 | 风险 |
| -------- | -------- | -------- | -------- |
| 普通聊天机器人 | 根据已有语言能力直接生成复习建议 | 上手快，适合解释概念、改写和头脑风暴 | 容易泛泛而谈，不知道本班资料 |
| 搜索增强问答 | 先搜索公开资料或通知，再回答 | 能补充较新的公开信息，适合查通知和背景资料 | 来源可能不权威，可能查到过期信息 |
| 文件/知识库问答 | 读取老师上传资料和错题解析 | 能围绕指定材料回答，更贴近本班课程内容 | 检索可能漏片段，材料本身可能过时 |
| 多模态工具 | 识别手写题、图片或实验装置图 | 能处理图片、手写和语音等非文本输入 | 成本高，相比纯文本更容易出错 |
| 代码/数据助手 | 统计错题分布、生成图表 | 适合计算、统计、批量整理和可视化 | 代码或数据处理工具调试繁琐、学习成本高 |
| 智能体工具 | 拆任务、调用工具、根据反馈调整 | 能处理多步骤任务，持续规划、执行和修正 | 权限、日志、人工确认要求更高，调试更困难 |

学生需要先判断任务属于哪种形态，再选择产品或模型，而不是一上来只问“哪个 AI 最强”。

### 4. 模型、产品和工具不是一回事

模型负责理解语言、生成文字、判断下一步。产品负责把模型包装成用户可用的网页、App、插件或系统。工具负责搜索、读取文件、运行代码、写日历、生成图片、调用数据库等外部动作。

因此：

- 模型不一定能联网，产品联网通常依靠搜索工具；
- 模型不一定能读文件，文件问答通常依靠上下文或 RAG；
- 模型不一定永久记住你上传的资料，长期记忆属于具体产品设计；
- 模型不一定能准确计算，复杂计算应交给代码、计算器或专门工具；
- 产品能自动操作真实系统时，必须有权限和人工确认。

### 5. 初步模型选型判断

选择模型或产品时，可以先问七个问题：

1. 任务是否只是简单整理、摘要、改写或格式转换？
2. 是否需要复杂推理、多步骤规划或严谨比较？
3. 是否需要处理长文档、课程资料或错题本？
4. 是否需要图片、手写题、语音或表格？
5. 是否需要最新信息或指定资料来源？
6. 是否涉及个人隐私、成绩、账号、家庭信息或真实操作？
7. 是否对速度、成本和稳定性有要求？

初步原则：

- 简单整理用速度快、成本低的模型；
- 复杂推理用推理能力更强的模型；
- 长文档用长上下文或 RAG 产品；
- 图片、语音、手写题用多模态模型；
- 最新信息要搜索并核查来源；
- 隐私敏感任务要关注本地化、权限和数据边界；
- 涉及正式评价、考试公平和真实操作时要人工确认。

### 6. 后续 8 课路线

本课建立地图，后面课程会依次回答：

```text
AI 为什么能聊天
  ↓
语言和资料怎样进入模型
  ↓
为什么 AI 有时会漏条件、算错或忘前文
  ↓
不同模型和产品为什么表现不同
  ↓
怎样写提示词
  ↓
怎样让 AI 完成复杂任务
  ↓
怎样设计一个复习助手智能体
```

学生会逐步理解这一节课中的选型的底层原理，并且能够更好地运用大模型的相关技术。

贯穿案例始终是“考前知识点复习助手”。

## 互动强化

**20 分钟活动：AI 产品身份侦探**

活动目标：让学生用更互动的方式把本节课的产品形态谱系和模型选型判断练熟。

### 活动材料

教师准备 8-10 张任务卡，例如：

1. “帮我把一篇 800 字作文润色得更通顺。”
2. “查一下学校最新人工智能竞赛报名截止时间。”
3. “根据老师上传的电磁感应讲义回答问题。”
4. “拍一张手写物理题照片，让 AI 帮我读题。”
5. “统计错题表里电路、电磁感应、力学分别错了几次。”
6. “每天晚上 8 点提醒我复习，但写入日历前要确认。”
7. “根据我的错题和老师讲义安排 5 天复习计划。”
8. “生成一张电路实验装置示意图。”

### 活动流程

1. 每组抽取 2 张任务卡。
2. 小组判断任务更适合哪种产品形态：普通聊天、搜索增强、文件/RAG、多模态、代码/数据处理、工具调用 Agent 或垂直学习助手。
3. 每组写出需要的输入、可能的输出、是否需要工具、是否需要人工确认。
4. 教师抽取 3-4 组汇报，并追问：这是模型能力，还是产品接了工具？如果没有这个工具会发生什么？
5. 全班把任务卡贴到黑板上的产品形态谱系中。
6. 教师最后回到复习助手案例：它不是单一聊天工具，而是可能组合了结构化提示词、RAG、错题统计、日程、反馈和安全审核的学习支持系统。

### 设备替代方案

有设备时，学生可以实际打开允许使用的 AI 工具观察功能入口。只有教师设备时，教师投影不同产品截图。无设备时，全部用纸质任务卡和黑板分类完成。

**20 分钟小作业：我的 AI 工具地图**

记录自己最近使用过或见过的 5 个 AI 工具，完成表格：

| 工具或场景 | 接收什么输入 | 输出什么结果 | 属于哪种产品形态 | 需要注意的风险 |
| ---------- | ------------ | ------------ | ---------------- | -------------- |
| - | - | - | - | - |

最后用 3-5 句话回答：为什么“模型”和“产品”不是一回事？

**拓展任务：** 选择一个学习任务，说明你会用普通聊天、搜索增强、RAG、多模态、代码工具还是智能体工具，并写出理由。

**可选模式：20 分钟课堂内容回顾题**

适合授课条件有限、无法安排课后设备实践的班级。

选择题：

1. 一个 AI 产品能回答最新校内通知，最可能依靠的是哪种能力？  
   A. 模型永久记住所有通知 **B. 联网搜索或校内资料工具** C. 温度参数 D. 字体识别
2. “模型不一定能联网”说明了什么？  
   **A. 模型和产品功能要区分** B. 所有 AI 都不能查资料 C. 联网一定不可靠 D. 只有开源模型能联网
3. 处理手写物理题照片时，通常需要哪类能力？  
   **A. 多模态能力** B. 只需要翻译能力 C. 只需要语音识别 D. 只需要日历工具

问答题：

1. 用自己的话解释“模型、产品、工具”三者的区别。
2. 复习助手如果要根据老师讲义回答问题，为什么可能需要 RAG 或文件问答功能？
3. 举一个需要人工确认的 AI 学习场景，并说明原因。

参考答案：1-B，2-A，3-A。问答题能说清“模型负责理解和生成，产品提供入口和功能，工具执行搜索/文件/代码等外部动作”即可。
