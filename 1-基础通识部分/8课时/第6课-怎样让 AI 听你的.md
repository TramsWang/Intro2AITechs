# 第6课：怎样让 AI 听你的

## 前一节课内容回顾

**3 分钟回顾：从“选择合适 AI”到“把需求说清楚”**

上一节课我们学习了不同 AI 为什么表现不同：训练数据、模型规模、预训练/指令训练/聊天对齐、上下文长度、工具能力和产品设计都会影响结果。我们还学习了用真实任务评估 AI，而不是只看宣传语。

作业点评时，可表扬测试问题设计清楚的答案。例如有同学用“解释概念、生成计划、处理错题统计、遇到未知范围如何回应”评估复习助手，这说明他已经能从任务角度看模型。教师承接本课：选对工具只是第一步，接下来还要把需求说清楚。很多 AI 输出不好，不是模型完全不能做，而是提示词没有把目标、限制和检查标准讲清楚。

## 内容引入

**3 分钟互动：一句话需求为什么不够？**

教师展示两个提示词：

```text
帮我复习物理。
```

```text
你是一名高中物理老师。学生下周三考试，薄弱点是电路分析和电磁感应，每天晚上可复习 45 分钟。请先列出两个知识点最容易混淆的地方，再用表格安排 5 天复习计划，最后给 6 道自测题。无法确认考试范围时，请标注“需要向老师确认”，不要承诺一定提高成绩。
```

请学生比较：第二个提示词多了哪些信息？哪些信息会让回答更具体、更可检查？

## 知识点讲授

### 1. 提示词为什么有效

大模型根据上下文生成后续内容。提示词就是给模型提供任务目标、背景、限制、格式和检查标准，让模型更容易生成符合要求的输出。

提示词不是魔法。它不能让模型知道没有提供的最新事实，也不能保证复杂计算一定正确，但它能显著减少模糊性、漏条件和格式混乱。

### 2. 复习提示词四要素

本课复习第 2 课的四要素，并用于更复杂任务：

| 要素 | 检查问题 | 复习助手例子 |
| ---- | -------- | ------------ |
| 任务 | 要 AI 做什么？ | 整理重点、安排计划、生成自测题 |
| 要求 | 必须遵守哪些限制？ | 每天不超过 45 分钟，不确定范围要标注 |
| 格式 | 输出长什么样？ | 表格、清单、题目和答案解析 |
| 场景 | 用户是谁、背景是什么？ | 下周三物理考试，电路和电磁感应薄弱 |

### 3. 提示词四原则

| 原则 | 常见问题 | 改进方式 |
| ---- | -------- | -------- |
| 全面性 | 漏了考试时间、薄弱点、可用时间 | 补齐影响结果的条件 |
| 一致性 | 要 5 天计划却要求 3 行表格 | 检查要求之间是否冲突 |
| 简洁性 | 抱怨很多但条件不清楚 | 删除无关信息，保留关键约束 |
| 合理性 | 要求一天 45 分钟完成 100 道大题 | 调整到真实可执行 |

### 4. 五种常用提示词技巧

**角色设定：** 让模型明确回答视角和边界。

```text
你是一名高中物理老师，请用适合高一学生理解的语言解释。
```

**样例提示：** 给模型一个输入和输出样例，让它模仿结构。

```text
请参考样例生成知识卡片：
知识点：欧姆定律
一句话解释：电流等于电压除以电阻。
易错点：不要混淆电压、电流、电阻单位。
自测题：已知 U=6V，R=3Ω，求 I。
```

**分步提示：** 要求模型按顺序完成任务。

```text
第一步整理混淆点，第二步安排 5 天计划，第三步生成自测题，第四步列出需要老师确认的内容。
```

**结构化输出：** 规定字段和格式，方便检查。

```text
请用表格输出：日期、复习目标、关键知识点、练习任务、检查标准、需要确认的内容。
```

**选择对话上下文：** 告诉模型应该使用或忽略哪些信息。

```text
请只依据下面这段学生信息制定计划，不要使用前面对化学复习的讨论内容。
```

### 5. 提示词迭代

提示词通常不是一次写完就最好。实际使用中可以按下面循环迭代：

```text
观察输出
  ↓
找出问题
  ↓
补充约束或样例
  ↓
要求自检
  ↓
重新测试
```

例如输出太泛，可以补充考试时间、薄弱点和输出格式；漏掉 45 分钟限制，可以把限制前置，并要求模型先复述约束；编造考试范围，可以要求“无资料时标注需要老师确认”。

### 6. 不同任务的提示策略

| 任务 | 提示重点 |
| ---- | -------- |
| 解释概念 | 说明对象年级、先直觉再例题、列易错点 |
| 总结文章 | 指定范围、输出层级、保留依据 |
| 写作修改 | 说明目标风格、保留原意、列修改理由 |
| 生成计划 | 写清时间、目标、限制、检查标准 |
| 出题自测 | 指定知识点、难度、题型、答案解析 |
| 分析错误 | 要求定位错因、对应知识点、补救练习 |
| 比较方案 | 说明评价标准和优先级 |

### 7. 提示词不能解决所有问题

提示词能改善输出，但不能替代所有工具和判断：

- 最新事实要搜索并核查来源；
- 复杂计算要用代码或计算器；
- 长文档要分段、摘要或使用 RAG 匹配指定资料片段；
- 隐私敏感内容要少输入或使用安全环境；
- 高风险判断要交给老师、家长或专业人员；
- AI 输出仍要检查依据和风险。

## 互动强化

**20 分钟活动：复习助手提示词迭代游戏**

活动目标：让学生体验“输出评估 -> 找问题 -> 改提示词 -> 再测试”的过程。

### 初始任务

```text
帮我复习物理，我快考试了。
```

教师说明真实需求：

```text
下周三要考物理，薄弱点是电路分析和电磁感应，每天晚上 45 分钟，希望得到 5 天计划和自测题。不确定考试范围必须标注。
```

### 角色分工

- 学生 A：检查输出是否满足要求，只指出一个最重要问题；
- 学生 B：提出改进方向；
- 学生 C：把改进方向写进新提示词；
- 教师：控制 3-4 轮迭代，并把有效修改写在黑板上。

### 活动流程

1. 教师展示初始提示词和第一次输出，或由学生现场测试。
2. A 指出问题，例如“没有控制每天 45 分钟”。
3. B 提出改进方向，例如“把时间限制放到提示词开头，并要求计划表每行不超过 45 分钟”。
4. C 改写提示词。
5. 全班观察新输出是否改善。
6. 重复 3-4 轮，直到输出基本满足任务、格式和风险要求。
7. 教师总结：哪些改动最有效，是补充角色、加约束、给格式、加样例，还是要求自检？

## 课后提升

**20 分钟小作业：写一份自己的学习提示词**

选择一个真实学习任务，写一版完整提示词，必须包含：

1. 任务；
2. 要求，至少 2 条约束和 1 个检查要求；
3. 格式；
4. 场景；
5. 至少使用一种技巧：角色设定、样例提示、分步提示、结构化输出或选择上下文。

最后写出：如果第一次输出不理想，你准备怎样迭代？

**拓展任务：** 查阅资料，了解什么是用户提示词（User Prompt）和系统提示词（System Prompt）。两者有什么区别？如何使用这两者提升提示词的质量？

**可选模式：20 分钟课堂内容回顾题**

选择题：

1. 提示词四要素不包括哪一项？  
   A. 任务 B. 要求 C. 格式 D. 模型显卡型号
2. 要让模型按固定字段输出，最适合使用：  
   A. 结构化输出 B. 随机闲聊 C. 删除背景 D. 提高噪声
3. 如果 AI 编造考试范围，较好的提示词改法是：  
   A. 要求无法确认时标注“需要向老师确认” B. 要求它必须猜 C. 删除所有限制 D. 让它更自信

问答题：

1. 写出一个包含四要素的复习提示词。
2. 说明角色设定和样例提示分别有什么作用。
3. 举一个提示词无法解决、必须用工具或人工确认的问题。

参考答案：1-D，2-A，3-A。
