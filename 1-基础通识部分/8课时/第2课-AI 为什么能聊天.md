# 第2课：AI 为什么能聊天

## 前一节课内容回顾

**3 分钟回顾：从“我在用哪类 AI”到“它为什么能回答”**

上一节课我们建立了 AI 技术和产品的全局地图：人工智能、机器学习、深度学习、大语言模型、多模态模型、RAG、工具调用和智能体不是同一层概念。模型负责理解和生成，产品把模型包装成可用功能，工具负责搜索、读文件、运行代码或执行真实操作。

作业点评时，可表扬能把工具分类说清楚的答案。例如有同学会发现“拍照识题”不只是聊天，而是图片识别、多模态理解和文字生成的组合；“根据老师讲义复习”不只是模型记忆，而可能需要文件问答或 RAG。教师用这些例子承接本课问题：既然大模型是很多 AI 产品的核心，它为什么能一句接一句地回答？

## 内容引入

**3 分钟互动：你来接 AI 的下一句**

教师给出几个开头，请学生快速接下一句：

```text
床前明月……
下周三要考物理，我最担心的是……
如果每天只有 45 分钟复习时间，我应该先……
电路分析和电磁感应总是混淆，可能是因为……
```

学生会发现：有些开头答案很固定，有些开头可以接出很多合理版本。教师追问：大模型聊天时，是不是也在根据前文判断“后面最可能出现什么”？

## 知识点讲授

### 1. 语言模型的核心任务

可以先把大语言模型理解为一种语言预测系统：

> 看前面的文字，估计后面最可能出现的词语或语言片段。

例如：

```text
下周三要考物理，我对电路分析和电磁感应总是混淆。每天晚上大概有……
```

模型会根据上下文判断后面可能是“45 分钟复习时间”“半小时学习时间”等表达。它不是从固定答案库里复制一整段回答，而是在当前上下文中逐步生成。

### 2. 连续预测怎样生成回答

模型每生成一小段内容，这段内容又会进入新的上下文，继续影响后续生成：

```text
我建议
  ↓
我建议先
  ↓
我建议先区分
  ↓
我建议先区分电路分析和电磁感应的核心概念
```

连续预测连接起来，就形成句子、段落、计划、自测题和对话回复。

复习助手生成 5 天计划时，也是先根据请求生成第一部分，再把已生成内容作为上下文继续补全后面的安排。

### 3. 概率和随机性

同一个问题可能有多个合理回答。模型在每一步通常面对一组候选 token，每个候选都有不同概率。生成时可以更保守，也可以更多样。

常见生成参数可以用直觉理解：

- 温度较低：更倾向选择高概率、稳妥的表达，回答更稳定；
- 温度较高：更容易选择多样表达，适合创意发散，但更可能跑偏；
- top-p 较低：候选范围更集中；
- top-p 较高：候选范围更宽，回答可能更丰富。

本课不要求学生掌握公式，只要理解：同一个问题答案不同，不一定说明模型“乱说”，也可能是生成机制允许多条合理路径。

### 4. 上下文为什么影响回答

模型根据上文生成后续内容，所以用户给出的背景、目标、限制和格式会影响输出。

对比两个请求：

```text
帮我复习物理。
```

```text
下周三要考物理，我对电路分析和电磁感应总是混淆。每天晚上大概有 45 分钟复习时间。请帮我整理重点、安排 5 天复习计划，并给我几道自测题。无法确认考试范围时请标注“需要向老师确认”。
```

第二个请求给出了考试时间、薄弱点、可用时间、输出要求和不确定处理方式，模型的预测空间更小，回答通常更具体、更稳定。

### 5. 提示词四要素和四原则

因为用户给出的上文会显著影响到模型输出的后文内容，所以我们期望让大模型完成准确、合理地完成一项任务的时候，要仔细准备输入给模型的提示信息、任务说明。这些由用户撰写的提示信息和任务说明就叫做“提示词”。

经过大量的工程实践，人们总结了撰写提示词的最基础的技术：“四要素”和“四原则”。

四要素：

| 要素 | 作用 | 复习助手例子 |
| ---- | ---- | ------------ |
| 任务 | 要完成什么 | 整理重点、安排 5 天计划、生成自测题 |
| 要求 | 必须遵守什么 | 每天不超过 45 分钟，不确定范围要标注 |
| 格式 | 怎样呈现 | 用表格列出每天安排，另列自测题 |
| 场景 | 背景是什么 | 下周三考物理，薄弱点是电路和电磁感应 |

四原则：

- 全面性：关键信息不要漏；
- 一致性：要求之间不要矛盾；
- 简洁性：保留有用条件，删除无关抱怨；
- 合理性：不要提出不符合现实的要求。

### 6. 会聊天不等于真正理解

大模型可以生成流畅文本，但这不等于它拥有真实经历、主观感受或自动事实核查能力。即使我们给了高质量的提示词，它仍然可能把看起来合理的语言生成出来，却没有事实依据。

这类错误常被称为幻觉：

> 模型生成看起来合理、但实际上不正确或不存在的信息。

复习助手如果说“你们老师一定会考楞次定律综合大题”，但没有课程资料或老师通知作为依据，这就是高风险回答。流畅不代表正确。

### 7. 训练阶段和使用阶段

学生日常提问时，通常是在“推理”或“使用”模型，不是在重新训练模型。大模型不像人脑一样，在日常使用的时候还在实时更新记忆和技能，大模型在训练结束之后参数固定，不再更新。

训练是模型在大量数据上长期学习语言规律和任务模式；推理是用户输入当前问题后，模型基于已有能力和上下文生成回答。

一次聊天不会让所有模型永久学会你的资料。某些产品可能有历史记录或记忆功能，但那是产品设计，不等于模型参数被即时改写。

### 8. 知识点讲授时间安排

| 时间 | 内容 |
| ---- | ---- |
| 2 min | 语言模型的核心任务：根据上文预测后续内容 |

| 3 min | 概率、随机性、温度和 top-p 的直觉 |
| 3 min | 上下文为什么影响回答 |

## 互动强化

**20 分钟活动：同一个问题的三种上下文**

活动目标：让学生直观体会“上下文越清楚，生成结果越稳定、越可检查”。

### 活动流程

1. 教师给出三个提示词版本：

```text
A：帮我复习物理。

B：下周三要考物理，请帮我安排复习。

C：下周三要考物理，我对电路分析和电磁感应总是混淆。每天晚上大概有 45 分钟复习时间。请用表格安排 5 天复习计划，并给我 6 道自测题；无法确认考试范围的内容请标注“需要向老师确认”。
```

2. 每组预测三个提示词可能得到什么差异：是否具体、是否可执行、是否有格式、是否会编造考试范围。
3. 有设备时，每组把三个提示词输入允许使用的 AI 工具，记录输出差异；无设备时，教师提供三段模拟回答。
4. 小组用四个维度给回答打分：具体性、可执行性、格式清楚、风险控制。
5. 每组把 A 或 B 改写成更好的提示词，必须包含任务、要求、格式、场景。
6. 教师抽取 2-3 组展示，追问：你们加入的哪条信息最明显改变了输出？
7. 最后全班总结：模型不是读心术，清楚上下文能缩小生成空间，但事实仍要核查。

选择一个真实学习需求，例如“帮我复习英语”“帮我准备演讲”“帮我整理错题”“帮我写作文提纲”。写出两个版本：

1. 模糊提示词；
2. 结构化提示词，包含任务、要求、格式、场景。

然后用 3-5 句话说明：第二个版本为什么更可能得到有用回答？

## 内容问答

1. 学生可能会问：如果模型只是预测下一个 token，为什么它看起来像真的理解了问题？

   推荐回答：因为模型在训练中见过大量语言、知识和任务模式，学会了在上下文中建立复杂关联。它能生成符合问题的解释和方案，但这仍然不等于它有人的经历、意识或自动核查事实的能力。

2. 学生可能会问：同一个问题每次回答不同，是不是说明 AI 不可靠？

   推荐回答：不一定。很多问题本来就有多种合理回答，生成过程也有概率和随机性。对于学习计划、表达润色等开放任务，不同版本可以都合理；但事实、计算和考试范围这类内容必须核查依据。

3. 学生可能会问：把温度调低是不是就不会出现幻觉？

   推荐回答：温度低通常会让回答更稳定、更保守，但不能保证事实正确。如果模型没有资料来源，或者题目本身缺信息，它仍然可能生成看似可靠但实际不对的内容。防幻觉更重要的是提供依据、搜索核查或使用 RAG。

4. 学生可能会问：提示词写得越长越好吗？

   推荐回答：不是。好的提示词是关键信息完整、要求一致、格式清楚、无关内容少。过长的提示词如果塞入大量抱怨、重复信息或冲突要求，反而可能让模型抓错重点。

5. 学生可能会问：我告诉 AI 一个知识点，它以后会一直记住吗？

   推荐回答：当前对话里它可能会参考这条信息；换一个新对话或换一个产品，就不一定还在。只有产品明确提供长期记忆、知识库或文件保存功能时，资料才可能被后续任务继续使用，而且也要看权限和设置。
