# 第3课：Token 是什么

## 前一节课内容回顾

**3 分钟回顾：从“生成回答”到“语言怎样进入模型”**

上一节课我们学习了大模型聊天的核心直觉：模型根据当前上下文预测后续 token，并通过连续预测生成回答。同一个问题可能得到不同表达，因为生成过程存在概率和可控随机性。提示词中的任务、要求、格式和场景会影响模型接下来生成什么。

作业点评时，可表扬能把模糊需求改成结构化提示词的答案。例如优秀作业会把“帮我复习物理”改成“下周三考试、薄弱点是电路和电磁感应、每天 45 分钟、用表格输出、无法确认范围要标注”。教师承接提问：我们一直说 token 和上下文，那么 token 到底是什么？人类写下的文字怎样变成模型能处理的输入？

## 内容引入

**3 分钟互动：模型看到的是字、词，还是别的东西？**

教师写出三段文本：

```text
电磁感应
electromagnetic induction
U=IR！！！
```

请学生猜：模型会不会一定按“一个汉字一个 token”“一个英文单词一个 token”“一个符号一个 token”来处理？

教师引导：模型处理文本前会先分词。token 是模型实际处理的基本片段，但它不等于一个字，也不一定等于一个词。

## 知识点讲授

### 1. 计算机处理的是数字

文字、图片、声音进入计算机后，都需要变成数字才能存储和计算。人类看到“电磁感应”会联想到磁通量变化、感应电流和楞次定律，但计算机底层先看到的是编码、编号和向量。

因此，语言进入大模型的第一步不是“像人一样理解”，而是转换成可计算表示。

### 2. Token 是模型处理文本的基本片段

大语言模型通常会先用分词器把输入切成 token。token 可以是一个汉字、一个词、一个词的一部分、一个数字片段、一个标点、一个空格，具体取决于分词器。

例如同一句话可能被切成：

```text
我 / 对 / 电路分析 / 和 / 电磁感应 / 总是 / 混淆 / 。
```

也可能被切成：

```text
我 / 对 / 电路 / 分析 / 和 / 电 / 磁 / 感应 / 总是 / 混淆 / 。
```

英文、公式、数字和标点也会参与切分：

```text
U=IR！！！
```

可能被切成 `U`、`=`、`IR`、`！！！` 或更细的片段。不同模型的切法不完全相同。

一般来说，一个 token 表达的是在概念上独立、在文法上不再细分的事物，所以中文对 token 的翻译定为“词元”。

### 3. Token 编号只是入口

分词器会把 token 转成编号，但编号本身只像“字典序号”，不能直接表示语义。模型真正用于计算的是 embedding 向量。

可以这样理解：

```text
文本
  ↓
token
  ↓
token 编号
  ↓
embedding 向量
  ↓
神经网络计算
```

编号告诉模型“这是哪个 token”，embedding 则把 token 放进一个可计算的语义空间。

### 4. Embedding：把 token 转变为向量

Embedding 是把 token 转变为实数向量的过程，也是把语义关系变成数字关系的过程。

Token 对应的向量表示它的语义特征。相近语义在向量空间中更接近。

例如：

- “电路”“电压”“电流”“电阻”在语义上较接近；
- “电磁感应”“磁通量”“楞次定律”在复习资料中经常一起出现；
- “焦虑”“担心”“紧张”比“焦虑”和“电阻”更接近。

Embedding 不是老师手动给每个词打标签，而是在训练或服务过程中，通过大量上下文让相关词、相似概念和常见关系形成可计算的距离。

### 5. Token 概念对使用有什么影响

理解 token 后，很多使用问题更容易解释：

- 长输入更慢、更贵，因为模型要处理更多 token；
- 长文档不宜无脑整篇塞入，可能需要分段、摘要或检索；
- 字母计数、精确字符统计、复杂格式对模型不友好，因为模型看到的是 token 和向量，不是人眼中的字符表格；
- 关键条件不要藏在大量无关文字里，否则模型可能没有充分利用；
- 上传文件不等于模型永久记住，通常只是临时放进当前任务能处理的输入范围。

### 6. 多模态模型的 token 怎样计算

多模态模型不仅处理文字，也能处理图片、声音甚至视频。这些非文本内容进入模型前，同样要变成可计算的片段。课堂上可以把它们粗略理解为“视觉 token”“音频 token”或“视频 token”，但它们不是用普通文字分词器切出来的。

图片通常会被缩放、切块或按区域编码。图像 token 数量常和这些因素有关：

- 图片分辨率和尺寸：更清晰、更大的图通常需要更多视觉 token；
- 细节模式：只看大概内容和读取图中文字、复杂图表，消耗可能不同；
- 图片数量：一次上传多张图，输入量会叠加；
- 模型和产品实现：不同产品的切块方式、压缩方式和计费规则不完全一样。

声音通常会被切成时间片段或声学特征，token 数量常和音频时长、采样质量、是否需要转写和模型处理方式有关。视频则更复杂，通常和视频时长、抽取多少帧、每帧分辨率、是否同时处理声音有关。

因此，多模态 token 不能简单理解成“一张图片等于一个 token”或“一秒语音等于一个 token”。更准确的判断是：输入越多、越清晰、越长、越需要细节识别，通常消耗越高、速度越慢。具体数量要以具体模型或产品的说明、计数器和价格规则为准。

### 7. Embedding 也是产品能力

Embedding 不只是模型内部的概念，也可以做成产品能力。很多的大模型提供方都会同时提供 Embedding 的接口服务。

它产生的向量有两个常见用法，需要区分清楚。

第一种是作用于 token 的 embedding。文本进入大语言模型时，通常会先被切成 token，再把每个 token 编号转换成向量。这些 token 向量会进入模型内部计算，帮助模型结合上下文理解关系、预测后续 token。

```text
一句话
  ↓
多个 token
  ↓
每个 token 对应一个向量
  ↓
进入大模型内部计算
```

第二种是作用于一段文本的 embedding。很多产品会把一句话、一段资料、一道题解析或一个文档片段整体转换成一个向量，用这个向量表示这段文本的大致语义。这样就可以比较“学生问题”和“资料片段”在语义空间里是否接近，用于相似内容匹配、资料检索、聚类和推荐等场景。

```text
一段文本
  ↓
embedding 模型整体编码
  ↓
一个表示整段语义的向量
  ↓
用于匹配、检索或分类
```

所以，token embedding 更像是模型读一句话时的内部零件；文本段落 embedding 更像是产品给一段内容做的“语义坐标”。二者都把语言变成向量，但粒度和用途不同。

### 8. RAG：embedding 的典型应用

RAG 是 Retrieval-Augmented Generation，中文常叫“检索增强生成”。它可以理解为：先从指定资料中找出和问题语义相近的片段，再让大模型带着这些片段回答。

RAG 的关键不只是关键词搜索，而是用 embedding 做语义匹配。系统会把资料片段转成向量，也会把学生的问题转成向量，然后比较这些向量在语义空间里是否接近。

复习助手中的 RAG 可以简化为：

1. 老师上传物理讲义、复习范围、错题解析；
2. 系统把材料切成较小片段；
3. 每个片段转成 embedding 向量；
4. 学生提问时，问题也转成 embedding 向量；
5. RAG 找出语义最接近的片段；
6. 大模型基于这些片段生成回答，并标注依据。

例如学生问“我总是把楞次定律和右手定则混在一起，怎么区分？”即使资料里没有完全一样的句子，RAG 也可能通过 embedding 匹配到“电磁感应方向判断”“楞次定律适用场景”“右手定则使用条件”等语义相近的讲义片段。

RAG 的价值是给大模型回答增加事实依据，让回答更贴近老师给定资料，减少凭空编造。它不是把资料永久训练进模型，也不能保证一定找对。片段可能不完整、过时或相关性不足，所以后续使用 RAG 时仍要检查来源、时间、片段完整性和回答是否真的基于资料。

## 互动强化

**20 分钟活动：输入怎样变成 token**

活动目标：让学生直观体会不同文本和多模态输入会带来不同 token 消耗，并理解为什么长文档、复杂格式和高清图片会让任务更慢、更贵。

### 活动材料

教师准备 8-12 张输入卡，每张是一段文字或一种输入场景，例如：

- 一句话：“解释楞次定律”；
- 一段 800 字错题解析；
- 一份包含公式、表格和编号的复习提纲；
- 一张清晰的实验装置照片；
- 三张手写题照片；
- 一段 2 分钟语音提问；
- 一段 30 秒实验视频。

每张卡片上标注“短/长”“简单/复杂”“文本/图片/音频/视频”等基本信息。

### 活动流程

1. 每组抽取 3 张输入卡。
2. 小组判断每张卡大概会产生“较少 token”“中等 token”还是“较多 token”，并写出理由。
3. 对文本卡，尝试画出可能的切分方式，观察中文词语、英文、数字、标点和公式会怎样影响切分。
4. 对图片、语音和视频卡，写出影响输入量的因素，例如分辨率、图片数量、时长、是否要识别细节。
5. 小组给出使用建议：哪些输入可以直接发给 AI，哪些应该先压缩、裁剪、分段或提取要点。
6. 全班总结：token 不是人眼中的字数；多模态输入也会占用模型处理资源，输入规模和细节要求会影响成本、速度和效果。

### 设备替代方案

有设备时，可以让学生使用产品自带的 token 估算、文件大小或图片分辨率信息做对比；无设备时，纸质卡片即可完成。
