# 第5课：不同 AI 为什么表现不同

## 前一节课内容回顾

**3 分钟回顾：从“AI 为什么会犯错”到“不同 AI 为什么错得不一样”**

上一节课我们学习了常见错误排查：AI 漏条件、抓错重点、算错题、忘前文、编造事实或格式混乱，可能来自提示词不清、上下文缺失、材料太长、注意力分配不理想、任务需要工具、模型能力不足或安全边界缺失。我们还初步区分了大模型和小模型：强模型更适合复杂推理和长链条任务，快模型更适合简单、低风险、高频任务。

作业点评时，可表扬能把错误分类和改进方法对应起来的答案。例如有同学能指出“错题统计出错”不应只改提示词，还应使用表格或代码工具；“编造考试范围”需要课程资料或老师确认。教师承接提问：为什么同一个问题放到不同 AI 工具里，有的回答具体，有的泛泛而谈，有的能查资料，有的不能？

## 内容引入

**3 分钟互动：同题不同答，谁真的更强？**

教师展示同一个问题：

```text
请根据我下周三物理考试的情况，安排电路分析和电磁感应的 5 天复习计划。
```

再展示三种假想回答：

1. A 工具给出通用复习建议，但没有问考试范围；
2. B 工具先要求上传老师讲义和错题记录；
3. C 工具生成计划，并标注“考试范围需向老师确认”，还能把自测题按知识点分类。

请学生判断：C 一定是模型本身更聪明吗？还是可能因为产品接了文件问答、题库、检查规则或工具？

本节课要解释：不同 AI 表现不同，可能来自训练数据、模型规模、训练目标、对齐方式、工具能力和产品设计。

## 知识点讲授

### 1. 训练和推理的区别

训练是模型长期学习的过程。模型在大量文本、代码、图片或其他数据上学习规律，通过错误反馈调整参数。

推理是日常使用时模型回答问题的过程。用户输入当前问题，模型基于已有参数、当前上下文和产品提供的工具生成回答。

学生平时聊天通常是在推理，不是在重新训练模型。一次提问会影响当前对话上下文，但不等于模型本身永久改变。

### 2. 机器怎样从数据中学习

可以用最简化方式理解机器学习：

```text
样本 + 目标
  ↓
模型做预测
  ↓
和目标比较，发现错误
  ↓
调整参数
  ↓
在更多样本上反复练习
```

参数不是答案表。它更像模型内部大量可调整的“连接强度”和“判断倾向”。训练会让模型把大量样本中的规律压缩进参数里，从而在新问题上迁移使用。

如果训练数据质量高、覆盖面广、目标设计合理，模型通常更稳定；如果数据过时、偏见多、错误多或某类任务样本少，模型在相关任务上就更容易出错。

### 3. 预训练、指令训练和聊天对齐

不同模型版本常常经历不同训练阶段：

- 预训练：学习大量语言和知识规律，模型很会续写，但不一定会按指令完成任务；
- 指令训练：学习“看到任务说明后怎样回答”，更能遵守用户要求；
- 聊天对齐：学习多轮对话、拒绝危险请求、语气友好、标注不确定和遵守安全边界。

可以把三者类比为：

```text
基座模型：会读很多书，也会接着写
指令模型：知道老师布置任务时要按要求回答
聊天模型：更适合对话，也更注意安全和礼貌
```

所以，同样叫“大模型”，有的更像续写器，有的更像任务助手，有的更适合多轮学习支持。

### 4. 能力边界来自数据、规模和目标

模型表现差异常见来源：

1. 训练数据时间边界：模型可能不知道最新政策、报名时间、产品价格、赛事结果或学校通知；
2. 数据质量：错误、偏见、重复和低质量数据会影响能力；
3. 领域覆盖：某些专业任务训练少，表现就可能弱；
4. 模型规模和结构：更大或更先进的模型通常能力更强，但成本更高；
5. 对齐目标：有些模型更重视安全和稳妥，有些更开放，有些更适合代码或数学；
6. 上下文长度：能处理的材料长短不同；
7. 工具调用能力：能否稳定选择工具、填参数、读返回结果。

### 5. 产品差异不等于模型差异

一个产品能做很多事，可能不是因为模型本身“全都会”，而是产品接入了工具：

- 联网搜索让它能回答最新信息；
- RAG、文件问答或资料库工具让它能先匹配老师资料，再把资料加入上下文让模型回答；
- 代码执行让它能统计错题、画图和验证计算；
- 多模态通道让它能看图片、读手写题或听语音；
- 日历和文件工具让它能保存计划、创建提醒；
- 安全审核模块让它能拦截作弊、隐私和高风险请求。

判断一个 AI 能力时，要问：这是模型能力，还是产品功能，还是外部工具？

### 6. 微调和“RAG/文件问答后再回答”的区别

学生常会把“让模型学会资料”和“让模型通过 RAG 或文件问答使用资料”混在一起。

微调更像改变模型在某类任务上的行为习惯或领域表达方式，例如让模型更会按某种格式回答、掌握某类客服话术或适应特定领域风格。

“查指定资料后再回答”更像让 RAG 或文件问答先匹配相关资料片段，把相关内容加入当前对话上下文，再让模型基于这些资料回答。复习助手读取老师讲义、错题本和复习范围，更常见的是这种流程，而不是把每份讲义都重新训练进模型参数。

简单判断：

| 需求 | 更可能使用 |
| ---- | ---------- |
| 让模型按固定格式、风格、任务习惯回答 | 微调或系统提示词 |
| 让模型基于最新公开信息回答 | 联网搜索 |
| 让模型基于老师讲义、错题解析等指定资料回答 | RAG 或文件问答 |
| 让模型统计错题表和生成图表 | 代码或数据工具 |

### 7. 怎样评估一个 AI 是否适合任务

不要只看排行榜或宣传语。可以用 3-5 个真实问题做小评测：

- 事实准确性：是否基于正确资料；
- 理解能力：是否抓住任务重点和限制；
- 推理能力：多步骤任务是否可靠；
- 格式遵守：是否按要求输出表格、清单或字段；
- 工具使用：是否知道什么时候联网搜索、调用 RAG、加入上下文或使用代码；
- 安全性：是否保护隐私、避免过度承诺；
- 速度和成本：是否适合高频使用。

例如评测复习助手时，可以用“生成 5 天计划”“解释楞次定律易错点”“根据错题统计薄弱知识点”“遇到未知考试范围如何处理”等问题进行比较。

### 8. 知识点讲授时间安排

| 时间 | 内容 |
| ---- | ---- |
| 3 min | 训练和推理的区别 |
| 3 min | 机器从数据中学习的直觉 |
| 4 min | 预训练、指令训练、聊天对齐 |
| 3 min | 能力边界：数据、规模、目标和上下文 |
| 3 min | 产品差异：搜索、RAG/文件问答、代码、多模态和安全审核 |
| 2 min | 微调和“RAG/文件问答后再回答”的区别 |
| 2 min | 任务评估和模型选择方法 |

## 互动强化

**20 分钟活动：给复习助手做小评测**

活动目标：让学生把“不同 AI 为什么表现不同”转化成可执行的比较方法。

### 活动流程

1. 教师给出 4 个评测题：

```text
1. 请解释电路分析和电磁感应最容易混淆的地方。
2. 请安排 5 天复习计划，每天不超过 45 分钟。
3. 如果无法确认老师考试范围，你应该怎样处理？
4. 根据下面 8 条错题记录，统计哪个知识点最薄弱。
```

2. 小组讨论每题主要考察什么能力：解释、规划、安全边界、计算统计、格式遵守或工具使用。
3. 有设备时，不同小组可在允许工具中测试不同 AI；无设备时，教师提供 A/B/C 三组模拟回答。
4. 小组用评分表评价：

| 维度 | 1 分 | 2 分 | 3 分 |
| ---- | ---- | ---- | ---- |
| 准确性 | 明显错 | 部分可靠 | 基本可靠且有依据 |
| 可执行性 | 空泛 | 有步骤但不完整 | 具体可执行 |
| 格式遵守 | 混乱 | 部分符合 | 完全符合 |
| 风险控制 | 过度承诺或编造 | 有少量提醒 | 明确不确定和人工确认 |
| 工具意识 | 不知道查/算 | 偶尔提到 | 能判断何时用工具 |

5. 每组汇报一个发现：哪类任务最能拉开不同 AI 的差距？
6. 教师总结：评估要看任务匹配，而不是只看名气。

## 课后提升

**20 分钟小作业：设计一个 AI 小评测**

选择一个学习任务，设计 3-5 个测试问题，并写出评分维度。任务可以是复习计划、作文修改、英语口语练习、数学错题讲解、资料总结等。

要求包含：

1. 每个测试问题考察的能力；
2. 至少 3 个评分维度；
3. 哪些问题需要联网搜索、调用 RAG、代码或人工确认；
4. 你会怎样判断这个 AI 是否适合长期使用。

**拓展任务：** 查阅资料，了解什么是机器学习的一般过程，了解并区分以下几个概念：
- 有监督学习
- 无监督学习
- 训练集
- 测试集
- 数据标签

**可选模式：20 分钟课堂内容回顾题**

选择题：

1. 日常向模型提问通常属于：  
   A. 训练 B. 推理 C. 删除参数 D. 硬件制造
2. 产品能联网回答最新信息，最可能是因为：  
   A. 模型天生知道未来 B. 产品接入了搜索工具 C. 字体更大 D. 温度更低
3. “RAG/文件问答后再回答”更像是：
   A. 改变模型参数 B. 先匹配相关资料片段、把资料加入上下文再回答 C. 删除上下文 D. 只生成图片

问答题：

2. 为什么不同 AI 回答同一问题会不同？
3. 设计一个评估复习助手的真实问题，并说明考察什么能力。

## 内容问答

1. 学生可能会问：同一个模型放在不同产品里，回答会一样吗？

   推荐回答：不一定。产品可能设置了不同系统提示词、工具、知识库、联网能力、安全规则和输出格式。即使底层模型相同，产品设计也会让实际体验不同。

2. 学生可能会问：模型训练数据越多，是不是一定越聪明？

   推荐回答：数据量很重要，但不是唯一因素。数据质量、覆盖领域、训练目标、模型结构、对齐方式和评估方法都会影响表现。大量低质量或过时数据也可能带来错误和偏见。

3. 学生可能会问：微调是不是比 RAG 更高级？

   推荐回答：二者解决的问题不同。微调更适合改变回答风格、固定流程或特定任务习惯；RAG 更适合让模型基于指定资料、最新资料或课程资料回答。复习助手读取老师讲义，通常优先考虑 RAG 或文件问答。

4. 学生可能会问：如果一个 AI 排行榜分数高，我是不是就可以放心用它做所有学习任务？

   推荐回答：不能只看排行榜。排行榜通常只覆盖某些测试维度，和你的真实任务可能不同。更可靠的方法是用自己的 3-5 个真实问题做小评测，观察准确性、依据、格式、工具使用和风险控制。

5. 学生可能会问：为什么有的 AI 不愿意回答某些问题？

   推荐回答：这通常和聊天对齐、安全规则和产品政策有关。AI 产品会限制作弊、隐私泄露、危险行为、过度承诺等请求。拒绝回答不一定是能力不足，也可能是在遵守安全边界。
